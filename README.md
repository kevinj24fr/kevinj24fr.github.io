# kevinj24fr.github.io

Source for [kevinj24fr.github.io](https://kevinj24fr.github.io/), the personal site of Kevin Joseph.

Plain static HTML + CSS, served by GitHub Pages from the `main` branch. No build step.

- `index.html` — the page
- `assets/css/style.css` — styles (light/dark via `prefers-color-scheme` and a toggle)
- `assets/js/main.js` — theme toggle only

To edit: change the files, commit, push. Pages redeploys automatically.
