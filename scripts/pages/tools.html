Tools

Open-source, mostly Rust, built because the existing route was slow or loaded everything into memory. Each line is the command as you would actually type it.

karnaTranscriptomic analysis engine. Single-cell, spatial, bulk, cross-condition. Out-of-core, seeded, content-addressed provenance DAG.
karna pipeline -i data.h5ad -o results/
karna spatial-map --reference results/ --query visium_sample/ --obs-column cell_type -o spatial/

marker FC vs Seurat r = 1.000 · GBMap 338K cells in 4 min vs 25

h5utilsQuery, validate, subset, split, merge, diff h5ad files without ever loading X.
h5utils query atlas.h5ad --obs --columns cell_type --value-counts
h5utils subset atlas.h5ad --genes markers.txt -o subset.h5ad
peek-seriesTwelve CLIs that read headers or stream one pass over FASTQ, BAM, VCF, BED, GTF, 10x, h5ad, CSV, JSON. Cost stays bounded with file size.
peek sample.bam   # auto-detects the format
fqpeek reads.fq.gz --json
atmanProteomics from Olink, SomaScan, MaxQuant, DIA-NN or Spectronaut, same commands on all of them. Every command writes a SHA-256 sidecar.
atman ingest-matrix --matrix protein_groups.tsv --samples sample_metadata.tsv --output-dir out
atman de --input-dir out --output-dir out --test welch-t --groups Case-Control
mpx2nwbAlpha Omega .mpx electrophysiology to NWB 2.7, in one step instead of three Python packages.
mpx2nwb --batch ./raw --outdir ./nwb --subject-field 2 --jobs 5

3.6× compression · merges split segments · refuses to merge across gaps

MicroFace / Py_MicrofaceSegmentation and morphometry of microglia from IBA1 images: 79 parameters per cell, 400,000 cells, four phenotypes, three injury zones. The method behind the iScience paper.

Also: kaRna_R (karna as a Seurat accelerator), karnaplot, GliomaEcology, SpatialNiches, scElectro, stTrace_R, FreiSpec, FastQRescue, cloupe-to-10x. Everything else is on the lab org and my profile.
